# ThreatLens AI — Gmail In-Mailbox Threat Shield Extension

Install the ThreatLens In-Mailbox Threat Score extension in Google Chrome, Microsoft Edge, or Brave in 30 seconds:

### Step-by-Step Installation:

1. Open **Google Chrome** (or Edge / Brave) and navigate to:
   `chrome://extensions` (or `edge://extensions`)
2. In the top-right corner, switch on **"Developer mode"**.
3. Click the **"Load unpacked"** button in the top-left toolbar.
4. Select the `extension` folder in this repository:
   `c:/Users/vishw/Documents/antigravity/excited-darwin/extension`
5. Go to [https://mail.google.com](https://mail.google.com) and open any email.
6. The real-time **Threat Score Badge** (`🚨 94/100` / `✅ 12/100`) will appear right beneath the sender's profile picture! Hover over it to inspect the full security breakdown.
